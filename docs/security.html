Policy

Security

These demos are visual components. They intentionally contain no real secrets, payment credentials, access tokens, or personal identity records.

Never commit sensitive data

  • real credit or debit card numbers
  • real CVV values
  • authentication tokens
  • government identity data
  • real ticket credentials
  • hotel room access secrets

Reporting

If you discover a security issue in the repository tooling, do not publish exploit details in a public issue. Follow the instructions in the root SECURITY.md.

Client-side storage

The customization studio stores optional design presets in localStorage. Do not adapt this mechanism to store confidential or authentication data.
