Contributing

Contributions should improve both the visual result and the quality of the source code. A card is not complete until its documentation, responsive behavior, and verification checks are also complete.

Before opening a pull request

npm run verify

New card checklist

  • Create a numbered folder under cards/.
  • Add index.html, style.css, script.js, and README.md.
  • Use the shared card studio unless the demo genuinely requires different interaction.
  • Add the card to the root gallery.
  • Document customization and integration.
  • Test keyboard interaction and reduced motion.
  • Use fictional data only.

Code quality

Prefer readable names, small functions, semantic HTML, CSS variables, and platform APIs. Avoid adding a dependency for something the browser already provides cleanly.

Visual quality

A contribution should feel intentional at 320 pixels wide as well as on desktop. Avoid excessive gradients, gratuitous glow, weak contrast, or controls that exist only to decorate the demo.
