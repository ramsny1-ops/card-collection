Build cards with a system, not guesses.

card-collection is a framework-free design laboratory for reusable card interfaces. The docs explain how to customize, embed, optimize, and contribute to the project.

What is included

The repository contains fifteen independent card demos. Each card ships with its own HTML, CSS, JavaScript configuration entry point, and README. The shared runtime provides a consistent customization interface without forcing a component framework.

AreaWhat you can change
ContentTitles, subtitles, labels, values, statuses, and supporting text.
Visual systemSurfaces, text color, accents, backgrounds, corner radius, scale, and pattern opacity.
TypographySystem sans, technical mono, and editorial serif presets.
MotionNone, float, pulse edge, pointer tilt, flip timing, and reduced-motion behavior.
PortabilityJSON export, CSS variable export, and local preset storage.

Repository philosophy

Every sample should be useful as source code, not only as a screenshot. Visual polish matters, but code readability, accessibility, performance, and documentation matter equally.

The finance, identity, ticket, and hotel demos contain fictional values only. Never use public UI examples to store real secrets, payment credentials, authentication material, or sensitive personal data.

Start locally

git clone YOUR_REPOSITORY_URL
cd card-collection
npm run verify
npm run serve

Browse independently

You can also open the root index.html directly. Each card folder links back to the gallery and can be copied independently into another project.
