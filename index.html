Cards people can actually build with.

Fifteen fully customizable card demos covering finance, identity, commerce, travel, dashboards, productivity, social profiles, pricing, and products. Every sample includes independent HTML, CSS, JavaScript, documentation, color schemes, typography controls, motion, flip behavior, responsive rules, import and export, and a professional integration guide.

Designed like a real open-source UI project.

The repository includes technical documentation, a contribution workflow, security guidance, issue templates, a pull-request template, changelog, roadmap, code of conduct, style guidance, and an automated verifier.

Built with standards-based HTML, CSS, and JavaScript. No framework, API key, paid service, or build step is required for the demos.
